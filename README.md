# SecretFlasherManaka: Escape from Manaka

这是适用于 Windows x64 版 `SecretFlasherManaka` 的扩展包。安装后可从标题页进入
新的撤离模式，使用装备、仓库、地图、任务和更新功能。

当前发布版本：`0.2.1`。

> 本 MOD 只适用于说明中对应的游戏版本。如果游戏本体更新后出现问题，请先等待
> MOD 发布兼容版本。

## 一键安装包

一键安装包位于仓库根目录：

```text
SecretFlasherManaka.EscapeFromManaka.Setup.exe
```

该安装包已经包含 MOD 所需的装备、地图、音频、字体、更新宿主和其他运行时资源。
关闭游戏后直接运行安装包，选择游戏主目录即可完成安装，无需手动复制文件。

## 安装

1. 关闭游戏。
2. 运行仓库根目录的一键安装包
   `SecretFlasherManaka.EscapeFromManaka.Setup.exe`。
3. 选择游戏主目录，通常包含以下文件：

```text
SecretFlasherManaka.exe
UnityPlayer.dll
GameAssembly.dll
SecretFlasherManaka_Data/
```

4. 点击 `Install / Update`。
5. 安装完成后直接启动 `SecretFlasherManaka.exe`。

安装器会：

- 备份并安装 `winhttp.dll`；
- 安装必要的自动更新组件；
- 安装完整装备、地图、音频、字体和版本资源；
- 安装 `EscapeFromManaka/uninstall.exe`；
- 删除旧版公开启动器，不创建桌面快捷方式。

游戏运行时不能替换 `winhttp.dll`。安装或更新前必须关闭游戏。

## 开始游戏

1. 启动 `SecretFlasherManaka.exe`。
2. 在标题页点击 `Escape from Manaka`。
3. 如果这是全新游戏环境，MOD 会通过原版流程创建默认手动存档槽 0。
4. 进入黑房仓库后，可整理装备、选择场景并开始撤离。

MOD 使用原游戏存档作为角色来源，但装备、背包、安全箱、仓库、快捷栏和展览柜
保存在独立的 MOD 库存文件中。

## 更新

日常使用中直接启动 `SecretFlasherManaka.exe` 即可。点击标题页的
`Escape from Manaka` 后，MOD 会先检查是否有新版本：

- 无更新：正常进入；
- 有更新：显示版本、文件数和下载大小；
- 点击更新：显示下载进度；
- 下载完成后：自动关闭游戏、替换文件并重新启动；
- 点击稍后：继续使用当前版本。

更新过程会自动校验下载内容，不需要手动替换文件。更新完成后游戏会重新启动。

## 黑房仓库

- 使用原存档角色的模型、动作和服装。
- 展示模型支持拖动旋转和动作切换。
- 装备、背包、安全箱和仓库之间支持拖放。
- 装备变化立即写入当前槽位的 MOD 库存文件。
- 拖拽物品时按 `R` 或鼠标右键可旋转当前物品。
- 提供 `1` / `2` / `3` 三个成人用品快捷格。
- 快捷格绑定实际物品，不会复制物品。
- 仓库页和局内都会显示 MOD 独立余额，单位为 `￥`，与原游戏 RP 无关。
- 右键仓库物品可选择“出售”，确认后物品会被移除，余额按物品当前价值增加。
- 穿着装备的奖励值会提高暴露状态下的周期收入；基础收益为每 5 秒 `￥100`。
- 局内 HUD 显示“本局获得金钱”。只有走撤离点成功撤离后才会加入余额；
  转移点、任务失败、系统菜单返回和异常退出都不会结算本局收益。

### 装备属性

装备共有十项属性。正值通常对玩家有利，负值表示对应机制减弱或需要付出代价。
单件装备显示值按“基础值 × 品质等级”计算：

| 品质 | 倍率 |
|---|---:|
| 白 | 1 |
| 绿 | 2 |
| 紫 | 3 |
| 金 | 4 |
| 红 | 5 |

| 属性 | 作用 |
|---|---|
| 感知力 | 眼罩状态下的可视范围 |
| 保守度 | NPC 正向怀疑值的增长效率，越高越不容易被发现 |
| 正常度 | 怀疑值开始下降前的等待时间和下降速度 |
| 忍耐力 | 爬行和振动器强档状态下的移动速度 |
| 速度 | 行走和奔跑状态下的移动速度 |
| 高潮速度 | 普通高潮值的累计速度和自然衰减速度 |
| 体力上限 | 最大体力与体力恢复等待时间 |
| 体力恢复 | 体力消耗倍率和恢复速度 |
| 手铐熟练度 | 普通手铐的解锁效率和解锁动画时间 |
| 奖励值 | 暴露状态下的金钱收益倍率 |

物品查看页只显示非零属性，正值蓝色、负值红色。将鼠标停在任意属性上可以查看
对应作用。装备页左上角会实时列出当前已穿戴装备的十项最终属性合计；穿脱装备后
立即更新。

### 展览柜

展览柜按装备系列和类别显示物品，支持：

- 默认排序；
- 放入时间正序/倒序；
- 价值正序/倒序；
- 磨损度正序/倒序。

未放入物品的展格显示灰色蒙版。红色已鉴定物品可放入展览柜；同一物品定义最多
收藏一件。点击展格可选择同类红色已鉴定物品进行替换，原展品会返回库存。

馆藏值用于展览柜等级、安全箱容量和鉴定品质概率计算。安全箱最多扩展到
`3x4`，等级详情可从展览柜进度条打开。

### 安全箱

安全箱容量会同步到局内和仓库界面。装备栏、背包栏、安全箱栏使用自适应正方形
格子，并按可用空间调整尺寸。

## 局内玩法

- 沿用原游戏的角色控制、移动和输入方式。
- 沿用原游戏场景和场景切换流程。
- 圆形小地图只显示玩家附近和本局可见信息。
- `M` 打开楼层大地图，支持缩放、拖动、楼层切换和点位追踪。
- 地图点支持物资、撤离、转移和任务随机点。
- 服装店和购物中心可加载撤离点配置。
- 支持搜索物资、任务、奖励物资、撤离和转移。
- 检测到原版任务失败界面后，自动结束本局并返回黑房。

## 文件与存档

MOD 库存和展览柜存档：

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\
  SaveData\EscapeFromManaka\inventory_<槽位>.json
```

## 卸载

1. 关闭游戏。
2. 运行 `EscapeFromManaka/uninstall.exe`。

卸载会移除 MOD 文件和安装内容，但不会删除 MOD 库存文件。完全清理时再手动删除：

```text
%USERPROFILE%\AppData\LocalLow\SheableSoft\SecretFlasherManaka\
  SaveData\EscapeFromManaka
```
